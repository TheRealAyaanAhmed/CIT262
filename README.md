# CIT262 Final Project
Project Name: Personal Portfolio Website

Author:
Ayaan Ahmed

Description:
This project is a personal portfolio website built using Python and Flask.
The website showcases my background, skills, projects, resume, and contact information.

Features:
- Multi-page website using Flask routing
- Home page with profile image
- About Me page
- Skills page with dynamically rendered skills
- Projects page with dynamically rendered project cards
- Resume page with downloadable PDF resume
- Contact page
- Custom CSS styling with a vintage minimalist theme

Technologies Used:
- Python
- Flask
- HTML
- CSS
- Jinja Templates

How to Run the Project:

1. Open the project folder in Visual Studio Code

2. Activate the virtual environment:

Mac:
source venv/bin/activate

3. Install Flask:

pip install flask

4. Run the Flask application:

python3 app.py

5. Open the local server in your browser:

http://127.0.0.1:5000
